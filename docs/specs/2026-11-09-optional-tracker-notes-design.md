# Optional work-item notes for findings and handoffs

A revision of `keep-the-findings` and `map-the-handoffs`, from the
2026-11-09 multi-agent orchestration research and Scott's rule that tracker paths
are OPTIONAL extra functionality. The wording below is the version
to ship.

## Why

Durable notes on a work item help when a session already tracks the
work there. They must never be required: a repository with only
files and a plan must keep working the same way. Local
`.kobold/findings/` and the plan's Handoffs heading stay the source
of truth. Structured notes on a work item, and links between items
when the tracker already supports them, are OPTIONAL mirrors.

## Skill: keep-the-findings

The description, Read first, and Write back match the skill file on
this branch.

## Skill: map-the-handoffs

The description and the new paragraphs under The graph match the
skill file on this branch.

## What this change does not do

It does not edit a past spec. It adds no key and no bound. It does
not require a tracker, a work item, or any API. It names no project,
host, or tool.
