# Carry out the plan: a bug you noted

A lesson from the weekly review of 2026-10-13. It revises
`carry-out-the-plan`. The wording below is the version to ship.

## The lesson

A session found a bug while running a task, recorded it in its
notes, and stopped. The user had to point at the note and ask for
the fix. The next session fixes a bug inside the task's files in
that task, and asks about one outside them.

## Skill: carry-out-the-plan

In The check, a paragraph after the one that starts "When a task
names no check."

### The check

A bug you find while running a task, inside the files that task
changes, is fixed in that task. Do not leave it only in your notes.
A bug outside those files is named in the reply, with the question
of whether to fix it now.

## What this change does not do

It does not widen a task past the files it changes. It does not
edit a past spec. It does not bump the plugin version.
